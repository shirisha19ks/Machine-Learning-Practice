# Machine Learning Practice

Welcome to my **Machine Learning Practice** repository.

This repository contains a collection of Machine Learning programs, practice notebooks, and prediction projects developed using **Python**. The main purpose of this repository is to practice different Machine Learning algorithms and understand how they can be applied to real-world datasets.

## 📌 Projects and Practice Notebooks

### 1. K-Means Clustering

Implementation of the **K-Means Clustering** algorithm to group similar data points into different clusters based on their characteristics.

### 2. Regression

Practice and implementation of **Regression techniques** for analyzing relationships between variables and predicting continuous numerical values.

### 3. Movie Review Analysis

A Machine Learning notebook focused on analyzing **movie review data** and understanding how ML techniques can be applied to text-based datasets.

### 4. Loan Approval Prediction

A Machine Learning model used to predict whether a **loan application may be approved or rejected** based on different applicant and financial attributes.

**Algorithm:** Random Forest

### 5. Insurance Premium Prediction

A prediction model developed to estimate **insurance premium values** using different customer-related features and Machine Learning techniques.

### 6. HR Employee Attrition

A Machine Learning project that analyzes employee information to predict **employee attrition**, helping identify patterns associated with employees leaving an organization.

### 7. Customer Purchase Prediction

A prediction model designed to analyze customer information and predict **customer purchasing behavior** using Machine Learning.

### 8. Customer Risk Prediction

A Machine Learning model developed to predict the **risk level of customers** based on available customer data.

**Algorithm:** XGBoost

### 9. Credit Card Default Prediction

A classification model designed to predict whether a customer is likely to **default on credit card payments** based on financial and customer information.

**Algorithm:** AdaBoost
